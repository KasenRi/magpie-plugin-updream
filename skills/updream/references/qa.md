# UPdream (Seedance) 视频抽帧质检（QA）与资产复用规范

**硬规则：任何生成的视频片段绝不能不看画面直接剪进成片。每段生成完成后必须先跑 `scripts/qa_clip.py` 做量化与抽帧检查，再人工/视觉逐项核验。**

---

## 1. 一键运行自动抽帧与运动/漂移检测

对单条片段或整个 `clips_raw/` 目录执行：

```bash
python3 .claude/skills/updream/scripts/qa_clip.py work/clips_raw/ -o work/qa_out
```

每条视频会生成两张检视图片与一组客观指标（写入 `work/qa_out/qa_report.json`）：

### （1）开头 / 中间 / 结尾三帧条（`<stem>_strip3.jpg`）
- **看什么**：
  - 机位是否真的固定（三帧背景窗框、桌沿位置是否大体一致，有无违规推近、拉远、环绕）；
  - 最后一帧产品是否被裁切出画；
  - 标题或信息卡片预留的留白区（如上方或左上角）在全时段是否干净无遮挡。

### （2）首帧与末帧 1:1 全尺寸对比 + 4 倍差分图（`<stem>_first_last_full.jpg`）
- **为什么必须看全尺寸首末对比（不能只看三帧缩略条）**：
  - 植物在 4 秒内缓慢张开 20%、产品悄悄变大变形，在缩小的三帧条里极易漏检！
  - 在 1:1 原生分辨率的 `[FIRST | LAST | |LAST-FIRST| ×4]` 三联图里：如果机位固定，背景窗框与花盆在右侧 `×4` 差分图里呈纯黑；一旦花瓣发生“延时开花”式扩张（如 `01-3` 的 `s02_canopy_breeze_v1`），整团花冠会在差分图里大面积高亮发光（中心变化率 ~69%，边缘变化率仅 ~22%），一眼就能抓出。

### （3）`tblend` 帧间运动量与累积漂移指标判读

`qa_clip.py` 内部调用 `ffmpeg -vf tblend=all_mode=difference,signalstats` 测量相邻帧平均亮度差 `step_yavg_mean`，并结合首帧到 `25% / 50% / 75% / 100%` 的累积漂移曲线自动打标：

| 自动告警 Flag | 触发条件与物理含义 | 处置建议 |
|---|---|---|
| `NEAR_STATIC_STILL_FRAME` | `step_yavg_mean < 0.30` 且首末变化像素 `< 15%`：画面几乎像一张死静帧图片 | 若分镜本意需自然生动感，增加可见物理动因（如喷雾水珠落花瓣、手指轻碰盆壁）后重做 |
| `HIGH_MOTION_OR_CAMERA_MOVE` | `step_yavg_mean > 4.5` 或边缘变化率 `> 55%`：存在明显运镜（推/拉/摇/环绕）或大幅动作 | 若非刻意安排的走动/手部入画，核查 `strip3.jpg`；属违规运镜则强化“固定机位”或改 `i2v` 返工 |
| `SUBJECT_GROWTH_OR_BLOOMING` | 帧间差很小（`< 3.5`）但累积漂移单调递增、中心区域变化大（`>= 35%`）：**典型的植物缓慢开花/生长或产品渐变变形** | 立即淘汰！删掉“盛放/绽放/舒展/呼吸”等词，截取完全开好的静帧改用 `i2v` 重生 |
| `HAS_SEEDANCE_AUDIO_TRACK` | 文件含音轨流 | 非对口型镜不应有音轨；对口型镜对齐后必须在剪辑时用 `-an` 剥离 |

## 2. 视觉必查 6 项清单（量化指标无法替代的语义质检）

打开生成的检视图片，逐条核对以下 6 项，任一项不合格即判定返工（或截取无瑕疵子时段）：

1. **人与产品真实尺寸比例（拿人头当尺子）**：
   - 以**成年人人头高度（约 `23 cm`）**作参照物比对同框产品。
   - 例：实高 `35 cm` 的盆栽同框时必须明显比人头高；若缩成茶杯大小（常见于自拍口播镜 `ref2v`）或贴镜头前景胀成巨物，立即判不合格，改用比例正确的合成/生成首帧走 `i2v` 或重写尺寸与同深度约束。
2. **唯一产品与外观还原**：
   - 全片只允许出现唯一一件目标产品；仔细扫视窗台角落、桌边背景有无偷偷多生出“第二盆小植物 / 第二个瓶罐”；核对产品颜色、配件（如花盆形状、支撑杆、材质）是否与参考图一致，背景是否误带入参考图的室外柏油路/水泥地。
3. **手脚结构、零穿插与多物件守恒**：
   - 手指必须五指自然，手掌/手指绝不能穿插进花瓣、尖刺或产品内部；
   - 换鞋、拿放包袋等交互镜头，逐帧看清旧鞋是否“原地融化变成拖鞋”或凭空消失——两件物品必须物理守恒同在。
4. **养护动作物理常识**：
   - 植物浇水养护镜头，水流必须从低位沿盆边浇到土面上；若从花朵头顶往下淋水，直接判不合格重做。
5. **人物视线纪律**：
   - 除指定的 1–2 个对镜说话镜头外，其余所有镜头里的人物**绝不能看镜头、绝不能对镜头笑**。
6. **无文字、无宠物、无油光假脸**：
   - 书页、包装袋、墙面无任何可读文字或伪造字幕；无猫狗等宠物；正脸皮肤无逆光金边和油腻塑料高光。

## 3. 局部裁切挽救与历史素材复用（省积分技巧）

1. **半段合格直接裁切复用**：
   - 若一条 5 秒双动作片段前半段（`0.2–2.1 s` 双手掂花盆）手型完美，仅后半段（`2.5–5.0 s` 浇水淋到花顶）不合格，直接保留前半段用于掂盆镜，只单独生成一条 4 秒低位浇土镜——立省一半返工积分。
2. **跨版本检索 `clips_raw/`**：
   - 开拍前先检查项目下已有试片（pilot）或上一版 `clips_raw/` 中的原始片段（哪怕当时未被选中）；只要通过上述抽帧质检且光线、机位一致（必要时用 FFmpeg `eq` / `colorbalance` 微调色温），直接 0 积分复用。
